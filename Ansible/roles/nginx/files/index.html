HTML. Файл для тестов

    Шаблон тестового html-файла для изучения структуры html-документа (веб-страницы), используемых тегов, элементов, атрибутов и тестирования кода JavaScript.

    HTML — это стандартный язык разметки для создания веб-страниц (html-документов).

    Сохраните полученный файл с именем test.html. Файл для тестов готов. Теперь, при двойном клике, test.html будет открываться в браузере по умолчанию:

    Тестовая страница
    Привет HTML и JavaScript
    После этой строки будем писать контент и вставлять тестируемый код

    Для проведения экспериментов и редактирования тестового html-файла хорошо подойдет продвинутый, но бесплатный, текстовый редактор Notepad++.

    Расшифровка html-элементов

    Расшифровка html-элементов, встречающихся в коде файла test.html:

    • <!DOCTYPE html> — объявление, которое указывает, что документ является документом HTML5.
    • <html> — корневой элемент html-страницы, между открывающим и закрывающим тегами этого элемента расположен весь html-документ.
    • <head> — элемент, который содержит метаинформацию (служебную информацию) о html-документе, которая не отображается на веб-странице.
    • <title> — элемент, определяющий заголовок html-документа для поисковых систем, который отображается на вкладке html-страницы в браузере.
    • <body> — элемент, являющийся контейнером для всего видимого содержимого веб-страницы.
    • <header> — элемент, представляющий контейнер для вводного контента или набора навигационных ссылок.
    • <h1> — заголовок верхнего (первого) уровня, который обычно используется для отображения основного заголовка веб-страницы.
    • <h2> — заголовок второго уровня (всего есть шесть уровней заголовков — от <h1> до <h6>).
    • <p> — элемент, определяющий абзац.
